# גמ״ח ברגע

פלטפורמה מלאה בעברית להשאלה חינמית של ציוד בין גמ״חים, משפחות וקהילות. האתר פועל כולו על Cloudflare — ללא Supabase וללא שירות מסד נתונים חיצוני.
TRIGGER: ACCESSABILITY UPDATE
[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/nh8030954-art/smachim/tree/gmach-karov)

## מה כלול

- קטלוג חיפוש וסינון לפי טקסט, קטגוריה, עיר וזמינות
- הרשמה וכניסה עם אימייל, סיסמה מאובטחת וקוד אימות דרך Resend
- עמודי גמ״ח ופריטים, תמונות, מועדפים ובקשות השאלה
- אזור אישי לניהול בקשות, זמינות, עריכה והסתרת פרסומים
- צ׳אט פרטי לכל בקשת השאלה בין השואל למנהל הגמ״ח
- התראות פנימיות על בקשות, הודעות ושינויי סטטוס
- מניעת אישור כפול כאשר כל היחידות תפוסות בתאריכים חופפים
- הערות אישור ודחייה ומנגנון דיווח על פריטים
- מסך מנהל לאישור גמ״חים ופריטים לפני פרסום
- ממשק RTL נגיש ורספונסיבי למחשב ולטלפון
- כל ההשאלות מסומנות ונאכפות כחינמיות בלבד

## תשתית

- **Cloudflare Workers** — API והגשת האתר
- **Cloudflare D1** — משתמשים, גמ״חים, פריטים ובקשות
- **Cloudflare R2** — תמונות פריטים
- **GitHub** — קוד המקור והפעלה אוטומטית של Workers Builds

## פרסום לחשבון Cloudflare

הדרך הקלה היא ללחוץ על כפתור **Deploy to Cloudflare** בראש הקובץ. Cloudflare ישכפל את הענף, ייצור ויחבר את D1 ו־R2, יריץ את המיגרציה ויפרסם Worker.

מיד לאחר הפרסום, פתחו בעצמכם את החשבון הראשון באתר. כל עוד עדיין אין משתמשים ומנהל, החשבון הראשון מקבל הרשאת מנהל אוטומטית. לאחר מכן אפשר להגדיר ב־Worker משתנה בשם `ADMIN_EMAILS` עם כתובות מנהלים נוספות, מופרדות בפסיקים.

לפרסום ידני:

```bash
npm install
npx wrangler login
npx wrangler d1 create gmach-karov-db
npx wrangler r2 bucket create gmach-karov-images
# מעדכנים את database_id שהתקבל בתוך wrangler.jsonc
npm run deploy
```

### הפעלת אימות אימייל עם Resend

1. מאמתים דומיין שולח ב־Resend ומוסיפים ב־Cloudflare DNS את רשומות SPF ו־DKIM שקיבלתם.
2. שומרים את מפתח ה־API כסוד ולא בקוד:

```bash
npx wrangler secret put RESEND_API_KEY
```

3. מגדירים ב־Cloudflare Workers את המשתנים `RESEND_FROM_EMAIL` ו־`SUPPORT_EMAIL`. כתובת השולח חייבת להיות מהדומיין שאומת ב־Resend.
4. פותחים `/api/health` ומוודאים שהשדה `email` הוא `true` לפני פתיחת ההרשמה לציבור.

ללא שלושת המשתנים האלה יצירת חשבון נעצרת עם הודעה ברורה, כדי שלא ייווצרו משתמשים שלא יכולים לאמת את כתובת המייל.

## פיתוח מקומי

```bash
npm install
cp .dev.vars.example .dev.vars
npm run db:migrate:local
npm run dev
```

Wrangler יפעיל את האתר, ה־API, מסד D1 מקומי ואחסון R2 מקומי. הקטלוג אינו מכיל פריטי דמה: הוא מציג רק גמ״חים וציוד שנוספו בפועל ואושרו לפרסום. ללא Worker פעיל מוצג מצב חיבור ברור, ולא תוכן מדומה.

## אבטחה והרשאות

- סיסמאות נגזרות עם PBKDF2-SHA-256, מלח אקראי ו־210,000 סבבים.
- אסימוני התחברות אקראיים נשמרים במסד רק כגיבוב, בעוגיית `HttpOnly`, ‏`SameSite=Lax` ו־`Secure` בפרסום.
- פרטי קשר אינם נחשפים בקטלוג. הם נמסרים רק לצדדים הרלוונטיים לאחר אישור בקשה.
- בעל גמ״ח יכול לערוך רק את הגמ״חים והפריטים שלו; פעולות ניהול דורשות תפקיד `admin` בצד השרת.
- העלאות מוגבלות ל־4 תמונות מסוג JPG, PNG או WebP, עד 5MB לתמונה.
- שיחות זמינות רק לשואל, לבעל הגמ״ח ולמנהל האתר; כל בדיקות ההרשאה מתבצעות ב־Worker.
- קודי אימות הם אקראיים, נשמרים רק כגיבוב, תקפים ל־10 דקות ומוגנים בהגבלת קצב.
- משתמשים רגילים יכולים למחוק את החשבון והמידע המקושר מתוך האזור האישי.

## לפני הפצה ארצית

יש לחבר דומיין מותאם, להפעיל את שלושת משתני הדואר, להפעיל 2FA למנהלים ולשנות את הסיסמה הזמנית. מומלץ להתחיל בפיילוט אזורי עם גמ״חים ופריטים אמיתיים, לעקוב אחר שגיאות ב־Cloudflare Observability ולהפעיל גיבויי D1 בהתאם למדיניות השמירה שלכם.

> זהו מוצר תוכנה ולא תחליף לייעוץ משפטי. לפני פתיחה לציבור מומלץ להשלים נוסח משפטי מלא, מדיניות פרטיות ופרטי קשר של מפעיל האתר.
